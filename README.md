# DAV-LAB

Lab programs for **Data Analysis and Visualization (DAV)** using Python.

## Experiments

| No. | Experiment | Notebook |
|-----|-----------|----------|
| 1 | Introduction to Python for Data Analytics: NumPy and Pandas basics, array operations, DataFrame creation, indexing, slicing | [Experiment_1_NumPy_Pandas.ipynb](Experiment_1_NumPy_Pandas.ipynb) |
| 2 | Exploratory Data Analysis: loading datasets, descriptive statistics, missing values and duplicates | [Experiment_2_Exploratory_Data_Analysis.ipynb](Experiment_2_Exploratory_Data_Analysis.ipynb) |
| 3 | Data Visualization using Matplotlib and Seaborn: histograms, box plots, scatter plots, pair plots, correlation heatmaps | [Experiment_3_Data_Visualization.ipynb](Experiment_3_Data_Visualization.ipynb) |

## Dataset
`student_performance.csv` - student study hours, attendance, GPA, internal and final marks (includes some missing values and duplicate rows for Experiment 2). Keep it in the same folder as the notebooks.

## How to run
```bash
pip install -r requirements.txt
jupyter notebook
```
