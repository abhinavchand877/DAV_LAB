# DAV Lab

Lab programs for Data Analysis and Visualization (DAV) using Python.

## Programs

1. `Exp1_NumPy_Pandas.ipynb` - NumPy and Pandas basics
2. `Exp2_EDA.ipynb` - Exploratory Data Analysis
3. `Exp3_Visualization.ipynb` - Data visualization using Matplotlib and Seaborn

## Dataset

`cafe_sales.csv` is used in Experiments 2 and 3. Keep it in the same folder as the notebooks.

## Requirements

```
pip install numpy pandas matplotlib seaborn jupyter
```
